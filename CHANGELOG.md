# Memail changelog

Product versions are separate from the preserved Bulwark compatibility version. [Upstream history](docs/UPSTREAM-CHANGELOG.md) remains available.

## 0.2.0-preview.1 — 2026-11-05

### Workspace and mail

- Labeled application rail, saved views, refined folders and consistent Heroicons.
- Inbox hierarchy, density controls, date tooltips and keyboard menus with command-prefix focus.
- Responsive reader metadata, recipient disclosure, attachment search and clearer filenames.
- Compact expandable formatting controls and inherited pasted-font feedback, preserving rich-text/Markdown/HTML workflows.

### Connected apps

- Settings finder expansion and filter-chip focus recovery.
- Calendar phone navigation, visibility checkboxes and responsive search with navigation within each pane.
- Contacts presence filters, persistent profile actions, property cards and section shortcuts.
- Files responsive paths, persistent actions, modal focus return and phone preview headers.

### Project

- Memail identity, deployment/release guides, synthetic gallery, Issues/Discussions and private vulnerability reporting.
- Sponsorship setup documented; no payment destination active yet.
- Bulwark ancestry, LICENSE and NOTICE retained. No ReUI adaptation or AI provider activation.

### Preview limits

Component/build verification does not replace real-account mail acceptance. Full Stalwart send/receive, reconnect, rich-paste recipient rendering and complete RTL/zoom/device checks remain stable-release gates. Available artifacts/platforms are listed in each release.

## 0.1.0-preview.1 — 2026-11-02

Initial branded Memail preview and deployment on the existing Stalwart backend.
