# Security policy

Report vulnerabilities through [private vulnerability reporting](https://github.com/Saivra/memail-webmail/security/advisories/new). Include the Memail tag/commit, server version, reproduction and impact. Do not include credentials or unrelated personal mail.

Memail is in public preview. Use the latest reviewed preview and follow Bulwark/Stalwart security guidance for shared components. A long-term support window or response-time SLA is not yet promised.

Maintainers will assess downstream and upstream impact, coordinate fixes, and publish advisories where warranted. Do not post unpatched exploits in public Issues or Discussions.
