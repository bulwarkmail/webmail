# Support Memail

Help by testing releases, reporting reproducible bugs, improving accessibility/localization, writing installation guides or sharing the project.

## Funding status

**No Memail sponsorship/payment destination is active yet.** Saivra does not currently have an enabled GitHub Sponsors listing. Donations will not be directed to a placeholder or unrelated account.

## Maintainer setup

1. Start [GitHub Sponsors setup](https://github.com/sponsors/accounts) for Saivra, or choose another supported funding provider. Check eligibility and fees directly with the provider.
2. The account owner completes identity, tax, payout and terms steps directly.
3. Use `.github/FUNDING.yml.example` to add the verified active account or exact funding URL to `.github/FUNDING.yml`.
4. Merge to the default branch and verify the Sponsor button's recipient. See [GitHub's funding guide](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/displaying-a-sponsor-button-in-your-repository).

Funding becomes active only after the recipient is confirmed. Bulwark can be supported separately through its upstream repository.
