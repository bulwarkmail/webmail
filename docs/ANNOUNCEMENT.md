# Memail public preview

Memail is an open-source, self-hosted JMAP webmail workspace for Stalwart. Mail, calendar, contacts and files share a focused interface, with consistent Heroicons, keyboard navigation and a rich-text composer.

This preview brings together the Memail UI work and the JMAP foundation of Bulwark Webmail. Memail is an independent downstream fork, distributed under the retained AGPL license. Upstream ancestry is preserved so future Bulwark developments can be reviewed and merged.

Try the synthetic demo locally, deploy a tagged source build, or help test rich-text paste, accessibility and Stalwart compatibility. Multi-provider AI is planned after core workflows are ready; this preview does not enable AI.
